# Working on Paint.MAC

Paint.MAC is a native macOS Swift/AppKit application, distributed as a Swift package and assembled into an app bundle by `scripts/build-app.sh`.

- Keep pixel operations and project serialization separate from AppKit interaction code.
- Document pixels use top-left coordinates and premultiplied RGBA8 or little-endian RGBA16 storage in the document’s tagged RGB profile. Masks remain L8 coverage. Layer ordering is bottom to top.
- `DocumentState.selection` is an immutable `SelectionMask` with linear 8-bit coverage. Nil means unrestricted editing; an empty mask selects nothing. Respect partial coverage in every pixel operation, and preserve holes in clipboard and move operations.
- Selection state participates in undo snapshots but is intentionally omitted from v1 project serialization. Pixel and selection history must restore together after crop and resize.
- Register undo once per user gesture using `PaintDocument.commit` or `edit`. Native NSDocument undo notifications handle edited-state tracking.
- Pressing the opposite mouse button cancels an active gesture by restoring its starting snapshot without touching undo/redo history. Ignore both buttons until released; fill previews also remain uncommitted until mouse-up.
- Middle-button drag pans without changing the selected tool, pixels, history, or inline text drafts. Forward middle-button input through text overlays and preserve their keyboard focus.
- Let `NSDocument.addWindowController` establish document ownership; do not set a controller's `document` property before adding it.
- Preserve existing project files and manifest-version validation. Read v1/v2/v3/v4/v5/v6 projects; write v6 for nondefault RGB format/resolution (exact raw premultiplied RGBA payloads and validated embedded RGB ICC profile), otherwise v1 for flat unmasked projects, v2 for masks alone, v3 for groups/clipping, v4 for editable text/effects, and v5 when locks are present. Validate exact L8 mask payload dimensions and preserve enabled state. Reject unsupported versions rather than dropping mask data.
- Run `swift test` after changes to raster behavior, history, or serialization. Build the app with `./scripts/build-app.sh release` to validate packaging.
- Avoid restarting a running app that contains an unsaved user canvas. Use a separate test document or the test suite for verification.
- Use native controls and AppKit input behavior. Rendering optimizations must preserve image orientation, alpha, and exported pixels.
- Inherit the system light/dark appearance. Resolve semantic panel colors in the view's effective appearance when updating backing layers, and refresh them on appearance changes; never freeze a startup CGColor or force dark mode.
- Sharp mode disables edge antialiasing without flattening intentional brush opacity or selection feathering. Keep this behavior consistent across raster tools and text.
- Canvas resize preserves pixel size and adds transparent padding; image scale resamples pixels. Prepare all resized layers before committing one history transaction, and transform selection masks alongside pixels.
- Inline text uses native NSEditor registration so close/quit detect drafts. Explicit save and document edits apply drafts; autosave defers while text is being entered. Keep draft undo separate from raster document history.
- Inline text displays raster pixels using the same layout as native input; commit the exact preview raster. Keep text layout vertically unbounded and clip its rendered pixels to the box so partial lines/glyphs survive. Do not introduce text scrollbars or native vector glyphs over the preview.
- Built-in image codecs live outside UI/document logic. ICO representations are alternate images, never compositing layers. Preserve untouched source payloads on replacement export; keep source-container context separate from v1 project serialization. Do not add dynamic plugin loading without a user request.
- ICNS slot identity includes point size and scale, not just pixel dimensions. Preserve unrelated resources and metadata on replacement, rebuild derived TOC resources, and update a selected legacy RGB resource together with its companion mask. Never choose a different same-size representation during decoding.

- Layer masks are immutable L8 coverage separate from original image pixels. Composite enabled masks before layer opacity. Route pixel tools to the selected image/mask target; true black hides, white reveals, gray is partial visibility. Preserve masks through duplication, crop/resize/scale, linked image movement, undo, and project save. Merge/apply bake coverage exactly once. The editing target and grayscale palette are session UI state.

- Layer hierarchy uses bottom-to-top postorder with descendants before their group header, contiguous subtrees, and validated group parent IDs (maximum eight group levels). Clip stacks stay within one parent, share the lowest unclipped base alpha, and inherit base opacity once. Use source-atop so soft edges do not expand. Group opacity/masks apply once after child compositing. Structural moves carry full clipping stacks; group duplication remaps all descendant IDs.

- Editable text stores content/style/geometry separately from its exact lossless raster cache. Finishing retains editability; only explicit Rasterize, Apply Mask, or merge may discard text metadata. Mask text remains raster painting. Preserve text creation clips and geometry through transforms, duplication, history, and save. Do not round fractional transformed boxes when reopening native input.
- Effect layers process lower siblings within one isolated parent. Use an alpha-mask interpolation for effect strength/coverage rather than source-over, and preserve base alpha for clipped effects. Effects cannot serve as clipping bases. Merge must include any lower input prefix needed by an unclipped effect. Preview sheets must not mutate document state/history before Apply.

- Inspector width is a UI preference, independent of document state/history. Keep the canvas usable when clamping pane sizes; preserve the preferred inspector width through window resizing. Divider drags must preserve zoom, selections, and native inline text drafts/focus.

- Onscreen compositing and live previews stay as CIImage graphs until rendered to the Metal drawable. CGImage materialization is reserved for CPU operations, export, snapshots, and fallback. Use viewport-sized premultiplied Display P3 half-float drawable output (with color-managed sRGB offscreen/test targets) with explicit top-left/Retina transforms; clear pixels outside the image on every frame. Render on demand, bound frames in flight without blocking input, and keep cursor/selection overlays separate. Metal failure must preserve artwork, history, and native text drafts while falling back to AppKit.
- Forward canvas invalidation from the requested needsDisplay value, not its getter: layer-backed AppKit views may report false immediately after accepting an invalidation. Schedule explicit Metal draws in common run-loop modes, including resize and backing-scale changes. Regression tests must exercise live editor updates without calling Metal draw directly or using a Core Graphics snapshot as proof of GPU presentation. Wait for both viewport dimensions before consuming the initial fit.
- Canvas display uses nearest-neighbor sampling at 100% zoom and above, and smooth downsampling below 100%, independently of tool antialiasing. Resolve compositing/effects on the document pixel grid before nearest sampling so Core Image cannot fuse fractional viewport transforms into filter evaluation. Keep the Metal and Core Graphics cutoff consistent, including on Retina displays.

- Layer locks protect image/mask/text/effect content, opacity, movement, and deletion; group locks protect descendants and group membership. Visibility, naming, selection, copying, and disclosure stay available. Whole-document crop/resize/scale retain locks while transforming every layer. Layer-row Delete removes selected nodes, canvas Delete clears pixels, and native text Delete edits text. Drag moves carry clipping units and complete subtrees, reject cycles/locked destinations, and commit one undo step; trash drops accept only this window’s layer drag.

- Painting with brush/fill/shapes on an unlocked visible group creates a pixel child as part of the gesture’s single undo snapshot. Cancel and empty gestures restore the original group, expansion, selection, and redo history. Shape previews use the new child’s blank raster, never the group’s placeholder. Group masks remain direct paint targets; erasing a group requires an explicit image/mask target.

- Hardness is independent of Sharp/Smooth: retain intentional falloff in Sharp mode. Hardness 100% uses the original hard rendering path. Soft brush/eraser gestures source-over evenly spaced dabs into a coverage mask and composite against their starting raster; maximum coverage creates X-shaped creases at crossings. Carry dab spacing across input events and ignore stationary events. Apply opacity/color alpha/selection once so crossings stay below stroke opacity; separate gestures still build paint. Lines and shape outlines support hardness, filled interiors stay solid, and tool opacity/selection coverage apply once to the combined fill/outline. Keep soft-shape work bounded to the affected region and preserve wide-ellipse performance.

- Shape and selection rail buttons remember their current type, including shortcut changes. Hover flyouts must preserve document state, undo history, inline text drafts, and keyboard focus; only choosing a tool finishes text. Keep flyouts nonactivating, mutually exclusive, and dismissible without swallowing the next canvas click.

- Pixel storage is sparse immutable TileGrid/PixelTile data, with uniform defaults. Live brush/eraser, shapes, text, and mask editing use bounded scratch regions; never materialize `.bytes` or `.coverage` once per pixel. These compatibility properties explicitly assemble contiguous buffers for codecs/global operations. Keep tile versions identical for no-op writes, reuse untouched versions, and render thumbnails at thumbnail resolution. Assemble tile sources before filtering/zoom so boundaries never show.
- Undo snapshots hold metadata and tile IDs, not full states retaining pixel buffers. HistoryTileCache persists/compresses/checksums unique versions off the main thread, evicts only verified disk-backed entries, and trims complete native undo groups to disk/metadata budgets. Active pixels/GPU frames own immutable RAM tiles independently. Load and validate an entire cold snapshot before publishing it; failed reads must leave artwork untouched. Session caches remain private, preserve other live processes via exclusive locks, and are removed on close. Legacy project formats v1–v5 remain readable; do not persist session history in projects.

- Preserve embedded RGB profiles and >8-bit sources on import. Profile conversion must transform sample values; never relabel ICC tags. All tools, editable text caches, merges, filters, geometric operations, and disk history must retain RGB precision/profile. Use RGBAf Core Image working intermediates in extended sRGB to preserve 16-bit precision and out-of-sRGB colors. The display’s precision is independent of stored precision. Explicitly convert JPEG/ICO/ICNS exports to 8-bit sRGB; PNG/TIFF retain RGB precision/profile.
- Resolution is document metadata in horizontal/vertical pixels per inch. Changing it without resampling preserves every pixel, mask, selection, and layer geometry; optional print-size resampling transforms all of them in one undo transaction. Retain resolution through project save and PNG/TIFF/JPEG export, and swap axes with EXIF orientation. New/legacy documents default to 72 PPI. Raster resolution is import/export context, not pixel equality.

- Layer-row context menus select the clicked row unless it already belongs to the multi-selection. Resolve actions against that row/selection; opening a menu must not alter pixels/history or fire eye/lock/disclosure buttons. Respect effective locks and shared group/move validation, expose type-specific actions, and keep bulk operations explicit. Empty table space has no row menu.

- Editor action icons use the pinned Apache-licensed Spectrum subset in Resources/Spectrum; retain unmodified SVGs, vector PDF derivatives, license/copyright, and provenance. Use EditorIcon mappings consistently in rail/flyouts/menus, native template tinting for controls, and explicit semantic tinting in custom drawing. Keep SF Symbols for standard macOS controls. Standalone packaging must include the resource bundle and notices; never rely on a developer build-directory fallback.

- Quick Mask is a session-only L8 selection buffer in DocumentState.quickMask. While active, DocumentState.selection is an independent local marquee; painting, text, move, erase, adjustments and clipboard target the temporary mask, regardless of layer locks/visibility. Red overlays selected coverage without entering exported composites. Q enters/exits atomically; preserve soft coverage, local marquee, and mode in disk-backed history without retaining pixel buffers in metadata. Transform both masks during crop/resize/scale. Off-image gesture anchors stay unmodified; pixel and selection rasterizers clip to canvas bounds.

- Geometry supports a live Option center origin (Shift constrains shapes/lines; Control constrains marquees). Selection combination is latched at mouse-down: Option before the drag keeps Subtract/Intersect; press Option after starting to center a marquee. Rectangle/ellipse outline alignment is Inside/Center/Outside relative to the dragged boundary, with Center retaining legacy output. Clip doubled strokes on the original path instead of shrinking ellipse axes or collapsing small rectangles; fill and outline opacity/selection apply once. Keep soft alignment work bounded and tool controls reachable at minimum window sizes.

- Quick Mask's rail button uses neutral template tint while off and the active tool style while on, including after keyboard toggles and undo/redo. The Layers-panel Add Layer Mask icon creates Reveal All on click and Hide All on Option-click (capture modifiers at mouse-down), on the active layer/group. Respect effective locks and existing masks; select the new mask as the editing target. Finish an active Quick Mask atomically with mask creation so one undo restores the prior mode and coverage. Preserve artwork and selection coverage.

- Marching ants animate only the AppKit overlay using cached selection contours; never invalidate the canvas/Metal artwork or rebuild coverage/contours on timer ticks. Keep dash lengths and speed in screen points across zoom. Stop timers for empty/deselected, hidden, occluded, or detached canvases and resume on exposure; timers and notification observers must not retain closed canvases.

- Rectangle/ellipse paint styles are Outline Only, Outline & Fill, and Fill Only. Outline/fill alone uses the gesture's main/alternate color; combined style uses the opposite color inside. Fill Only ignores border size, alignment, and hardness and uses the exact dragged geometry. Rail/flyout shape icons reflect the remembered style; lines remain strokes. At shared antialiased inside boundaries partition fill/outline coverage, rather than multiplying independent edge masks, so opaque outlines never leak a fill-colored fringe. Retain color alpha, tool opacity, selection coverage, RGB precision, and bounded scratch rendering.

- Rectangle and Rectangle Select share Square/Round/Squircle/Bevel/Scoop/Notch corner geometry with a pixel radius clamped to half the shortest side. One shared path builder drives painting, selection coverage, and icons. Painted borders support Solid/Dotted/Dashed on rectangles, ellipses, and lines; dash length/gap use image pixels, dot spacing stays fixed across nested soft strokes, and patterned wide inside strokes must never take the solid-fill shortcut. Capture corners/borders at gesture start, preserve undo/cancel/Quick Mask/RGB precision, and leave marching ants independent of painted dash settings. Numeric tool settings commit on Return or focus loss without mutating artwork/history; keep additional controls reachable through horizontal scrolling without resetting scroll position on every field change.

- Align to Pixels is independent of Smooth antialiasing for geometric shapes and marquees. Snap rectangle/ellipse minimum bounds down and maximum bounds up on their image-space grid regardless of drag direction; keep aligned edges unchanged, expand constrained sides equally, and expand center-origin bounds symmetrically around the snapped center; use integer boundaries for fills/selections/inside/outside outlines and half-pixel centers for odd-width centered outlines. Quantize only the aligned gesture’s outline width, preserve center-origin/equal-side constraints, off-image anchors, masks, precision, undo/cancel, and existing Sharp output. Remember shape/marquee preferences separately; tool settings never edit document state/history.

- Hard Sharp 1 px ellipse outlines use thresholded area coverage in the bounded shape-mask path, avoiding Quartz’s conservative aliased widening of doubled Inside/Outside strokes. Threshold geometric coverage before applying colors, tool opacity, selection feathering, and precision-aware compositing; retain binary edges without flattening intentional alpha. Keep smooth/soft and wide-ellipse paths unchanged.

- Retouch (Blur/Sharpen/Smudge) edits existing image/mask/Quick Mask pixels through bounded premultiplied float scratch buffers in the tagged RGB profile. Use fixed image-space dab spacing carried across events, ignore stationary input, capture stroke settings at mouse-down, and apply selection coverage once per dab. Blur uses padded separable passes across tile boundaries with clamped canvas edges; Sharpen preserves alpha and clamps premultiplied channels; Smudge picks up a relative brush patch without editing on click, then mixes the unpainted canvas into a reusable spatial reservoir before depositing each dab. Use 5% image-space spacing, distance-normalized Length retention independent of Strength, and uniform pickup across the entire patch/padding; apply softness only when depositing so stale fringe colors cannot form rails; Length 0 and Strength 0 are no-ops. Preserve Alpha locks original per-pixel alpha (including transparent pixels and 16-bit low bits). Capture Length/Preserve Alpha at gesture start, reuse bounded SIMD scratch, and never read back freshly painted pixels for the same dab. Preserve 16-bit low samples, tile sharing, locks, undo/cancel/redo, native focus and pan. Retouch never creates an empty child when a group is selected; it requires existing pixels or a mask. Strength is independent of paint opacity/colors.

- Large-image CI sources use immutable TileImageProvider snapshots with top-left, padded-row callbacks for RGBA8/RGBA16 and L8 coverage; preserve the constant-image fast path. Do not reconstruct long source-over tile graphs or assemble full CPU buffers for display. Metal encoding runs on its serial render queue, with one outstanding frame and latest pending viewport; capture AppKit/document state only on main. Present checkerboard and artwork together. Layer thumbnails render off main at output resolution, coalesce pending versions per target, reject obsolete completions, and cache only small output images/version IDs; pixel invalidation reuses native layer-row controls.

- Move gestures retain immutable source/selection graphs, cache cut/lifted and stationary content, and translate the existing overlay mask/contours without mutating state per pointer event. Commit pixels and the translated selection once on mouse-up (or explicit save/tool change); opposite-button/Escape cancellation preserves redo. Cut/source-over arithmetic uses the document's encoded RGB profile, not a relabeled working space. CPU moves touch only source/destination tile regions, preserve exact 8/16-bit mask rounding and unchanged tile versions. Keep editable off-canvas text recoverable from metadata during previews and commit.
